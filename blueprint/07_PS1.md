# Console Blueprint 07 — PlayStation 1

## Purpose

Major capstone covering a 32-bit MIPS CPU, exceptions, DMA, command-driven GPU, VRAM, textured primitive rasterization, the GTE, CD-ROM, audio, and serious Metal acceleration.

## Prerequisite

SNES certification complete.

## Core Rule

Do not begin with a Metal-only GPU implementation.

Build a CPU/reference GPU path first so Metal can be tested against known-correct behavior.
