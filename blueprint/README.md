# Emulator Course Blueprint Pack

This pack is designed to be handed to an AI coding agent one console at a time.

## Files

- `HOW_TO_USE.md` — exact workflow for running the course with an AI agent.
- `MASTER_BLUEPRINT.md` — permanent course rules and teaching philosophy.
- `AGENT_START_PROMPT.md` — reusable prompt to start or resume a console.
- `01_CHIP8.md` — CHIP-8 course, including Metal from zero.
- `02_8080_SPACE_INVADERS.md` — Intel 8080 + Space Invaders.
- `03_GAME_BOY.md` — Game Boy DMG.
- `04_NES.md` — NES.
- `05_GBA.md` — Game Boy Advance.
- `06_SNES.md` — SNES.
- `07_PS1.md` — PlayStation 1 capstone.
- `08_NDS.md` — Nintendo DS advanced course.

## Recommended Order

1. CHIP-8
2. Intel 8080 / Space Invaders
3. Game Boy
4. NES
5. Game Boy Advance
6. SNES
7. PlayStation 1
8. Nintendo DS

Do not hand all console files to the agent at once. Give the agent only `MASTER_BLUEPRINT.md`, `HOW_TO_USE.md`, `AGENT_START_PROMPT.md`, and the current console blueprint.
